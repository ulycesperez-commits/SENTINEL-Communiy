SENTINEL LIVE THREAT MAP - FEED FIX

1. Extract this ZIP to a new folder.
2. Make sure Node.js 18 or newer is installed.
3. Double-click START_SENTINEL.bat.
4. Keep the black window open.
5. Open http://localhost:3300

This build uses the Feodo Tracker botnet C2 IP blocklist instead of the retired ThreatFox export URL. It refreshes every 5 minutes. IP geolocation is approximate and may fail independently of the feed. A working feed does not mean your computer is infected or that attacks are being observed live. This dashboard is for viewing public threat-intelligence indicators; it does not scan, clean, or block devices.

Source: https://feodotracker.abuse.ch/blocklist/
Map: OpenStreetMap via Leaflet.
